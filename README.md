# Karte BW

Offline-Vektorkarte für Baden-Württemberg (mit Randstreifen) im OpenMapTiles-Schema,
monatlich automatisch aus OpenStreetMap-Daten (Geofabrik) mit Planetiler gebaut und
als PMTiles in Teilen auf GitHub Pages bereitgestellt (`bw/verzeichnis.json`, `bw/teil.000` …).

Die Rechnungs-App lädt daraus nur den Ausschnitt um den eigenen Ausgangspunkt.
